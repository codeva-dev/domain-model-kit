# Change Log

All notable changes to this project will be documented in this file.
See [Conventional Commits](https://conventionalcommits.org) for commit guidelines.

## 0.1.0

- First non-prerelease release, published under the npm `latest` tag.
- Pure, neverthrow, and Effect adapters for aggregates, domain events, repositories, persist handlers, and domain errors.
- Class-first Effect services with inferred handler event types and dependency layer types.
- Effect domain errors retain their schema surface and omit runtime causes from encoded payloads.
- Repository-root package with GitHub installation support and a private TypeScript examples workspace.
- Adapter-specific order examples and an installable boundary-focused usage skill.
